# Prompt Templates for LLM Analysis

This directory contains prompt templates used by the LLM clients for paper analysis.

## Files

- `digest.md` - Standard digest summary format
- `simple.md` - Simplified explanation format
- `concepts.md` - Atomic concept extraction format
- `scoring.md` - Paper quality scoring prompts
- `filter.md` - Fast relevance filtering

## Usage

Prompts are loaded by the LLM clients and can be customized by editing the markdown files.
